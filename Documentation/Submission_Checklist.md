# Submission Checklist

- [ ] Build scene from the CS4104 menu and save it.
- [ ] Confirm no red Console errors.
- [ ] Capture full station screenshot in Scene view.
- [ ] Capture Game view showing dashboard and pedestrians.
- [ ] Capture incident active and inactive states.
- [ ] Run baseline and blocked-exit trials at least three times each.
- [ ] Fill measured values into an experiment-results table.
- [ ] Capture Unity Profiler CPU/GPU frame-time evidence.
- [ ] Explain nearest-exit selection, separation steering and CharacterController.
- [ ] State limitations honestly; do not describe prototype results as validated real-world predictions.
- [ ] If headset VR is required, configure OpenXR and XR Interaction Toolkit separately and test on actual target hardware.
